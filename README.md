# 宿舍状态共享站

一个面向四人宿舍的轻量状态共享 Web App。成员通过邀请码加入同一个宿舍，实时查看彼此的休息、学习、活动和外出状态，减少因信息不同步造成的打扰。

**API 地址：**
<https://room433-d3gzju0tf27b2d998-1526277682.ap-shanghai.app.tcloudbase.com/dormsyncApi>

## 核心功能

- 创建宿舍并通过邀请码或分享链接加入
- 同一成员账号可以绑定手机、电脑等多台设备
- 支持 8 位短时设备绑定码和 20 位长期账号恢复码
- 支持查看登录设备、撤销其他设备和退出当前设备
- 当前成员的状态行自动置顶并突出显示
- 支持四种状态：
  - 睡觉中
  - 正常活动
  - 专注学习
  - 外出
- 支持状态留言、预计结束时间与自动过期
- 首页自动计算安静人数和预计安静结束时间
- 每 5 秒自动同步，页面切回前台时立即刷新
- 网络断开时保留最近数据并显示离线状态
- 创建者可重新生成邀请码、移除其他成员；创建者退出后自动移交给下一位成员
- 成员可修改昵称、默认状态，或退出宿舍
- 手机浏览器优先，同时兼容桌面浏览器
- 支持 PWA manifest 和基础离线缓存
- 已禁止双指缩放

## 使用流程

### 第一位成员

1. 打开在线地址。
2. 选择“创建宿舍”。
3. 填写宿舍名称和昵称。
4. 创建后进入“室友”页。
5. 将邀请链接或邀请码发送到宿舍群。

### 其他成员

1. 打开邀请链接，或进入网页后选择“加入宿舍”。
2. 输入邀请码和昵称。
3. 加入成功后，每位成员只会修改自己的状态。

每台设备的令牌保存在当前浏览器的 `localStorage` 中。创建或加入成功后，应立即保存账号恢复码。

> **注意：** 网页版不能自动读取微信号。同一个人的手机和电脑需要在已登录设备生成一次绑定码，之后会共享同一个成员身份。

### 绑定第二台设备

1. 在原设备进入“设置”的“账号与设备”。
2. 点击“绑定新设备”，生成 8 位绑定码。
3. 在新设备选择“绑定已有账号”并输入绑定码。
4. 两台设备可以同时在线，状态自动同步。

### 恢复账号

1. 在新设备选择“绑定已有账号”，再选择“使用恢复码恢复”。
2. 输入创建账号时保存的 20 位恢复码。
3. 恢复码长期有效，也可以在设置中重新生成；重新生成后旧码立即失效。

每个账号最多绑定 5 台设备。旧设备丢失且没有保存恢复码时，只能由房主移除成员后重新加入，原成员身份无法恢复。

## 状态与过期规则

| 状态 | 是否影响安静提醒 | 结束时间 |
| --- | --- | --- |
| 睡觉中 | 是 | 必填 |
| 正常活动 | 否 | 不需要 |
| 专注学习 | 否，单独显示学习提醒 | 可选 |
| 外出 | 否 | 不需要 |

安静人数只统计当前有效的“睡觉中”成员。状态到达结束时间后，前端会立即按正常活动显示，云函数在下次读取时也会执行服务端过期恢复。

输入限制：

- 宿舍名称最多 20 个字符
- 成员昵称最多 12 个字符，同一宿舍内不能重名
- 状态留言最多 30 个字符
- 邀请码为 6 位，不区分大小写

### API 约定

浏览器通过 `POST` 调用 `dormsyncHttp`，请求体格式如下：

```json
{
  "action": "getState",
  "memberToken": "member-token"
}
```

| 操作 | `action` | 是否需要成员令牌 |
| --- | --- | --- |
| 创建宿舍 | `createRoom` | 否 |
| 邀请码加入 | `joinRoom` | 否 |
| 绑定新设备 | `claimDeviceLink` | 否，需要绑定码 |
| 使用恢复码恢复 | `recoverAccount` | 否，需要恢复码 |
| 获取宿舍状态 | `getState` | 是 |
| 更新状态与留言 | `updateStatus` | 是 |
| 修改昵称和默认状态 | `updateProfile` | 是 |
| 重新生成邀请码 | `regenerateInvite` | 是，仅创建者 |
| 移除成员 | `removeMember` | 是，仅创建者 |
| 退出宿舍 | `leaveRoom` | 是 |
| 生成设备绑定码 | `createDeviceLink` | 是 |
| 查看登录设备 | `listDevices` | 是 |
| 撤销设备 | `revokeDevice` | 是 |
| 重新生成恢复码 | `rotateRecoveryCode` | 是 |

业务结果统一返回 `{ "ok": true, "data": ... }` 或 `{ "ok": false, "error": ... }`。普通业务错误通常仍使用 HTTP `200` 返回，调用方需要读取 `ok` 字段判断是否成功。

## 安全设计

- 每台设备拥有独立随机令牌，浏览器保存原文，数据库只保存 SHA-256 哈希。
- 绑定码 5 分钟有效、只能使用一次，数据库只保存哈希。
- 恢复码为 20 位随机值，数据库只保存哈希，重新生成后旧码立即失效。
- 每个账号最多保留 5 个有效设备会话。
- 所有状态和成员操作都通过云函数校验令牌。
- 普通成员只能修改自己的昵称和状态。
- 只有创建者可以重新生成邀请码或移除成员。
- 被移除或退出宿舍时，该成员的全部设备会话立即失效。
- 退出当前设备只撤销该设备令牌，不会把成员移出宿舍。
- 邀请码重新生成后，旧邀请码不能再加入。
- 前端代码不包含数据库账号、密码或服务端密钥。

## 隐私与数据

服务只保存宿舍运行所需的数据：

- 宿舍名称、邀请码和创建者标识
- 成员昵称、恢复码哈希、加入时间和最近同步时间
- 设备标签、设备令牌哈希、最近在线和撤销状态
- 当前状态、状态留言和预计结束时间

当前版本不收集手机号、邮箱、定位、通讯录或微信账号信息。业务数据存储在项目所属的腾讯云 CloudBase 环境中，前端不会直接连接数据库。

邀请码和邀请链接只用于加入宿舍，请发送到可信的宿舍群。设备令牌相当于个人钥匙，不会通过界面分享；不要把浏览器 `localStorage` 中的令牌发送给其他人。设备绑定码和账号恢复码也不要发送到宿舍群。

### 新环境部署

如果更换 CloudBase 环境，需要：

1. 创建 CloudBase 环境，并开通静态网站托管。
2. 创建 PostgreSQL 共享实例并开启 Document 扩展。
3. 修改 `cloudbaserc.json` 中的 `envId`。
4. 创建 `.env.local`，填写新的环境 ID 和 API 地址。
5. 使用 `npx tcb login` 登录对应云开发账号。
6. 执行 `npm run deploy`。
7. 在 CloudBase 控制台确认 HTTP 云函数网关路径为 `/dormsyncApi`。

首次调用云函数时会自动创建 `rooms`、`members`、`statuses`、`deviceSessions` 和 `deviceLinks` 集合。

## 资源与容量

当前 CloudBase 体验版每月提供 `3000` 资源点，环境 QPS 配额为 `500`。单个四人寝正常间歇使用余量充足；多个宿舍长期同时在线时，需要关注云函数调用量、PostgreSQL 读写量和 5 秒轮询成本。

每个保持打开的页面约每小时产生 `720` 次 `getState` 调用。少数宿舍日常使用压力较小；如果面向大量宿舍公开推广，应重点观察 CloudBase 的资源点消耗、云函数调用量和数据库读写量。

如果用于较大规模或商业场景，建议：

- 升级 CloudBase 套餐
- 绑定正式备案域名
- 将轮询改为更节省调用的实时订阅
- 增加数据库索引与调用监控

## 已知限制

- 当前使用 CloudBase 体验版测试域名，首次访问有一次平台安全提示。
- 网页版不读取真实微信号，需要主动绑定设备或输入恢复码。
- 每个账号最多绑定 5 台设备，达到上限后需要先撤销一台。
- 清除站点数据或更换设备后，如果恢复码也丢失，将无法恢复原成员身份。
- 微信小程序版本尚未创建。
- 自动同步采用 5 秒轮询，不是 WebSocket 长连接。
- 离线时只能查看最近缓存的数据，不能可靠提交新的状态修改。
- 默认不发送浏览器推送、短信或微信通知。
- CloudBase 体验版有效期到 `2027-05-20`，不会自动续费。
- 默认 CloudBase 域名中的 `room433` 来自环境 ID，页面标题和产品名称仍是“宿舍状态共享站”。如需彻底更换域名，需要绑定用户自有且已备案的正式域名。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 首次打开等待约 20 秒 | CloudBase 测试域名的平台确认，点击“确定访问”即可 |
| 提示“登录状态已失效” | 当前设备已被撤销，或成员已被移除；使用恢复码或重新加入 |
| 换手机后如何保留原身份 | 使用已保存的恢复码，或在旧设备生成 8 位绑定码 |
| 绑定码在哪里生成 | 设置 > 账号与设备 > 绑定新设备，绑定码 5 分钟内有效 |
| 绑定码泄露了怎么办 | 绑定码只能使用一次且会在新码生成时失效，也可直接撤销未知设备 |
| 忘记恢复码怎么办 | 旧设备仍在时可重新生成；所有设备都丢失时只能联系房主移除后重新加入 |
| 输入邀请码后无法加入 | 确认邀请码未轮换、宿舍未满 4 人，且昵称没有与现有成员重复 |
| 看不到室友的新状态 | 等待最多 5 秒；确认网络正常，并尝试切回页面触发立即刷新 |
| 看不到邀请码或成员管理 | 只有当前创建者可以进行邀请码轮换和移除成员操作 |
| 原创建者退出后怎么办 | 房主身份会自动移交给仍在宿舍中的下一位成员 |
| 页面能打开但操作一直失败 | 检查 API 地址、CloudBase 环境状态和 PostgreSQL Document 扩展是否正常 |
| 地址里为什么还有 `room433` | 这是 CloudBase 按环境 ID 生成的默认域名，不影响产品名称，可用自定义域名替换 |

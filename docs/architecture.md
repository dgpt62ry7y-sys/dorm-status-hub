# 宿舍状态共享站架构

## 身份

- 每名成员通过创建宿舍或邀请码首次加入。
- 服务端生成随机成员令牌，前端保存在当前浏览器的 `localStorage`。
- PostgreSQL 只保存令牌的 SHA-256 哈希。
- 成员数据读取、状态修改和成员管理操作都必须携带有效令牌。

## 数据

CloudBase PostgreSQL 开启 Document 扩展后，使用三个文档集合：

- `rooms`：宿舍名称、邀请码、创建者、容量和关闭状态。
- `members`：成员昵称、身份、令牌哈希、加入时间和活跃状态。
- `statuses`：每个成员当前唯一的宿舍状态。

## API

- `dormsyncHttp`：CloudBase HTTP 云函数。
- 网关路径：`/dormsyncApi`。
- 浏览器通过 HTTPS 调用，不直接访问数据库。
- 创建、加入、邀请码轮换和成员管理使用文档数据库事务。

## 权限

- 普通成员只能修改自己的昵称和状态。
- 创建者可以重新生成邀请码和移除其他成员。
- 被移除或退出宿舍的令牌立即失效。
- 邀请码更新后旧邀请码不能再加入。

## 同步与到期

- 前端每 5 秒获取一次最新宿舍状态。
- 页面切回前台时立即刷新。
- 云函数读取时将已经到期的睡眠或学习状态恢复正常活动。
- 网络失败时保留最近数据，并显示离线状态。

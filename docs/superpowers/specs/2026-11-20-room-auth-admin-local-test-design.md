# 寝室授权、版本提示与本地测试环境设计

日期：2026-11-20

状态：已实现并发布

## 弹窗滚动

- 弹窗打开后固定主页面当前位置，关闭时恢复原滚动位置。
- 拦截弹窗外的触摸滚动。
- 弹窗内滚动区域到达边界后不得继续带动主页。
- 使用移动端触摸事件进行验证，不只测试鼠标滚轮。

## 创建密钥

- 新建寝室时必须输入创建密钥。
- 密钥错误立即拒绝，不创建寝室、成员、状态或通知记录。
- 密钥只保存在 CloudBase 云函数环境变量中。
- 前端、README、Git 和本地测试代码不得硬编码真实密钥。
- 创建成功后寝室标记为已授权。
- 使用短密钥期间增加失败次数限制。

## 存量寝室验证

- 功能上线时没有授权标记的寝室进入待验证状态。
- 当前房主第一次访问待验证寝室时，开始 12 小时倒计时。
- 房主看到阻塞式验证弹窗，未验证不能继续使用。
- 普通成员也锁定页面，但只显示等待房主验证的信息。
- 房主输入正确密钥后寝室永久标记为已授权。
- 错误密钥可以重试，但受失败次数限制。
- 功能上线后 3 天内房主始终未访问的存量寝室也会清理。
- 清理寝室时同时删除成员、状态、设备会话、绑定码和公告领取记录。
- 清理任务使用 CloudBase 定时触发器执行，并在请求时做兜底检查。

## 只读管理站

- 管理站仅在本机运行，不进入正式网站构建产物。
- 使用单独管理密钥，不保存到浏览器长期存储。
- 管理接口只读，不提供删除、延长或强制通过操作。
- 只显示寝室名称、房主、人数、容量、创建时间、最近活动和验证状态。
- 不返回成员状态、留言、设备令牌、创建密钥或管理密钥。

## 版本红点

- 页面加载时比较前端构建版本和服务端当前版本。
- 不在 5 秒轮询中实时刷新版本提示。
- 有新版时，设置导航显示红点。
- 设置页版本区域显示“有新版本，请刷新页面”。
- 点击刷新后更新 Service Worker 并重新加载页面。

## 本地独立测试版

- 使用本地内存数据库，不接触正式 CloudBase 数据。
- 首次启动为空环境。
- 只允许 localhost 使用测试控制接口。
- 支持一键初始化一个六人寝和六个测试账号。
- 支持在同一页面切换六个账号。
- 支持重置全部虚拟数据和浏览器令牌。
- 使用正式版代码和 UI，不维护独立业务实现。
- 测试控制和账号切换不会进入正式生产构建。

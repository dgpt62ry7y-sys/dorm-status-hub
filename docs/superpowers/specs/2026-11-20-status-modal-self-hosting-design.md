# 状态体验与 GitHub 自托管改造设计

日期：2026-11-20

状态：阶段一已发布，阶段二已完成文档与部署安全改造

## 阶段一：状态与弹窗体验

### 弹窗滚动

- 任意弹窗打开时锁定页面主文档滚动。
- 弹窗自身允许滚动时，滚轮和触摸滚动优先作用于弹窗。
- 多个弹窗嵌套时使用引用计数，只有最后一个弹窗关闭后才恢复页面滚动。

### 外出状态

- 外出与专注学习一样支持可选留言。
- 外出必须填写预计回寝时间。
- 到达预计回寝时间后自动恢复正常活动。
- 成员卡片显示预计回寝时间。

### 到期恢复

- 睡觉、专注学习和外出到期后都恢复正常活动。
- 到期后清空成员留言。
- 删除前端和后端的“预计时间已结束”文案。
- 不保留已经过期的预计结束时间。

### 版本

- 本阶段发布为 `1.4.0`。
- 在发布摘要中说明新增加的外出回寝时间、弹窗滚动和到期体验。
- 完成后部署并验证正式环境，再进入阶段二。

## 阶段二：自托管与 GitHub 展示

### 部署安全

- `.env.example` 只包含占位符，不指向维护者环境。
- 新增跨平台 Node 部署脚本。
- 部署脚本从 `CLOUDBASE_ENV_ID` 或 `.env.local` 的 `VITE_CLOUDBASE_ENV_ID` 获取环境 ID。
- 云函数和静态托管命令都显式传入 `--env-id`。
- 构建前检查 `VITE_CLOUDBASE_ENV_ID` 和 `VITE_DORMSYNC_API_URL`，缺失或仍为占位值时失败。
- 保留当前 `cloudbaserc.json` 作为维护者默认配置，但 npm 部署入口不得依赖它选择环境。

### 文档

- 新增 `docs/self-hosting.md`。
- 以项目当前真实能力编写，包含四人寝和六人寝、账号多设备、更新公告等现状。
- 明确在线演示与自行部署的费用和数据边界。
- README 顶部提供在线体验、自行部署、架构说明导航。
- 保持 README 的核心功能、安全说明、隐私说明和常见问题。

### 限制

- 不修改业务 API、数据库结构和身份验证逻辑。
- 不修改线上 CloudBase 资源配置。
- 不改变 GitHub 仓库 Private/Public 状态。
- 不添加开源许可证。
- 不虚构 CloudBase 价格或错误码。
